# 雪の結晶シミュレータ（snow-crystal-sim）仕様

## 目的

温度と過飽和度によって雪の結晶の形が変わる現象（中谷ダイヤグラム）を、**結晶が雲の中を
落下する軌跡をマウスで描く**という操作で体験させる。利用者は中谷ダイヤグラム上のマーカーを
ドラッグし、結晶がその条件の履歴を形として記録していく様子をリアルタイムに観察できる。

**ターゲット**: 小中学生〜一般（雪の結晶の多様さの理解）、および理科・地学の指導者。

**実験・観察に対する優位点**: 実物では制御できない条件を操作できること。すなわち
(1) 温度・過飽和度を連続的に変えながら1つの結晶を育てられる、(2) 同じ条件を再現できる、
(3) 成長の履歴を巻き戻して見られる。

## 範囲

### 必須

- 中谷ダイヤグラム（横軸=温度、縦軸=過飽和度）上のマーカーをマウスでドラッグでき、
  ドラッグ中は結晶が成長し続ける
- 条件が変わると、**それ以降の成長だけ**が新しい形態になる（六角板の外周から樹枝が伸び
  始める、など）
- 温度により板状／柱状・針状が切り替わり、過飽和度により枝分かれの度合いが変わる
- 成長した結晶を 3D で表示し、カメラで回して観察できる
- 成長履歴をタイムラインのドラッグで巻き戻し・早送りできる
- 同じ条件（seed と軌跡）で同じ結晶を再現できる

### 対象外

- **雲の鉛直構造のモデル化**。落下速度・高度・気温減率から (T, σ) を導くことはせず、
  利用者が直接 (T, σ) を指定する
- **着氷（riming）・併合**。雲粒が付着して曇った結晶になる過程は扱わない
- **融解・昇華による形の崩れ**
- 結晶どうしの衝突・凝集（雪片の形成）
- モバイル・タッチ操作の最適化

## 物理モデル

### 現象の二層構造

結晶形態は独立した2つの軸で決まる。**この分離が本アプリの設計の基礎である。**

| 層 | 支配要因 | 決めるもの | 手法 |
|---|---|---|---|
| 異方性 | 温度 | 板状か柱状（角柱・針）か | c軸／a軸の成長速度比。単純な幾何 |
| 不安定性 | 過飽和度 | 単純な六角形か樹枝状か | 水蒸気拡散のセルオートマトン |

出典に基づく根拠:

- 「-5°C では針状（c軸）の成長が支配的であり、-15°C では a軸に沿った枝分かれが最も
  顕著である」（Libbrecht）
- 「形態の複雑さは、どの温度でも過飽和度の増加とともに増す」（Physics Today）

**2次元の平面セルオートマトンだけでは針状・柱状を作れない。** それらは c軸方向の
伸長という本質的に3次元の形態だからである。二層に分けることで、CA は基底面内の
枝分かれだけを担当し、柱状は六角柱の c軸方向への伸長という幾何で表せる。

### 温度による形態（中谷ダイヤグラム）

低過飽和度側で温度を下げていくと「六角板 → 角柱 → 板 → 角柱」と交替する
（Physics Today）。代表的な温度帯:

| 温度 | 形態 |
|---|---|
| 0 〜 -3 °C 付近 | 小さな板・星状 |
| -2 °C 付近 | 薄い板状 |
| -3 〜 -10 °C | 針状・細長い角柱 |
| -6 °C 付近 | 細い柱状 |
| -7 °C 付近 | 中空の角柱 |
| -15 °C 付近 | 大きく薄い板状（a軸方向の枝分かれが最も顕著） |
| -30 °C 以下 | 再び柱状 |

### 過飽和度

縦軸は氷平面に対する遠方の相対過飽和度
`σ∞ = (c∞ - csat(T)) / csat(T)` である。`c∞` と `csat(T)` は水蒸気の数密度、`σ∞` は
無次元であり、UI では `100σ∞` [%] を表示する（Libbrecht 2023, 式 (1), p. 4）。
入力範囲は **0〜30 %** とする。30 % は自然界の普遍的上限ではなく、Libbrecht らの
自由落下 chamber 測定が覆う 0.5〜30 % を含む有限の製品範囲である
（arXiv:0811.2994v1, Abstract p. 1）。有限な範囲外入力は最近傍端へクランプする。

湿度が低く成長が遅いと単純な形になり、湿度が高く成長が速いと複雑な枝分かれ形になる
（Libbrecht）。数値軸は確定したが、`(T, σ∞)` から Reiter CA の `β`、`γ` への写像は
物理的同一視ではなく、Libbrecht (2023) Figure 2 の 206 点を T1-7 で追跡可能なコーパスへ
固定し、T1-8 で形態タグと無次元形状との比較に基づき経験的に較正する。物理時間と実寸は
照合・報告するが、CA step に物理秒を割り当てないため適合対象にしない。ただし 0 % の
平衡端点は Reiter の `β=0, γ=0` に固定し、成長なしとする。

### 成長コア（セルオートマトン）

基底面内の枝分かれを、六角格子上の水蒸気拡散セルオートマトンで表す。各セルは
「氷か否か」と「水蒸気量」を持ち、1ステップで局所拡散と凍結判定を行う。

**⚠ 本アプリで最も重要な但し書き**

`(温度, 過飽和度)` から CA のパラメータへの対応付けは、**観測される形態領域に合わせた
経験的な較正であり、第一原理から導いたものではない。** 理由は2つある。

1. 中谷ダイヤグラムの板／柱の交替そのものが、**約50年にわたり未解明の研究課題**である
   （Physics Today: "For some 50 years, many researchers have grappled with the challenge
   of explaining that alternating plate-prism growth sequence"）
2. Reiter モデルのパラメータ（α: 拡散、β: 背景水蒸気量、γ: 水蒸気の添加量）は温度・
   過飽和度そのものではない。より物理的な Gravner–Griffeath の3次元モデルでさえ、
   「多数の自由パラメータは緩くしか拘束されておらず、大まかな物理的解釈しか許さない」
   とされ、有望な形態を得るためにパラメータ空間を探索している

したがって本アプリは、**この対応付けが較正であることをヘルプ画面に明記する**（AC-12）。
較正の手順と採用した値は実装時の `DESIGN.md` に記録する。

### 六回対称性の扱い

**対称性を強制してはならない。** 六回対称性は次の物理から**創発させる**。

- 六角形の基本形は氷の結晶構造に由来する
- 6本の腕は、結晶が雲の中を漂う間、**同じ環境を共有する**。温度や湿度が変われば
  すべての腕が同時に同じ変化を受けるため、歩調が揃う
- 一方で**腕どうしは互いに情報をやりとりしない**。各腕は独立に成長するため、
  実際の結晶が完全に対称になることはない

したがって実装は次のとおりとする。

- **格子全体を計算する。60° セクターだけを計算してミラー・回転で複製してはならない**
  （それは実在しない完全対称を作ってしまう）
- 6本の腕が同じ (T, σ) の履歴を受けることで、対称性は結果として現れる
- 微小なゆらぎを与えることで、実物と同様の「ほぼ対称だが完全ではない」形になる。
  ゆらぎの大きさは較正対象とする

> 補足: 実験室で条件を一定に保つと、ほぼ同一の結晶を繰り返し作れることが知られている。
> 実物の不揃いは結晶化の物理ではなく大気条件の変動に由来する。

### 単位と座標の規約

- 温度は °C、過飽和度は氷平面に対する遠方の相対過飽和度 `100σ∞` [%]
- 角度は内部でラジアン、UI 境界のみ度。変数名に `Rad` / `Deg` を付す
- 基底面（a軸平面）を **XZ 平面**、c軸を **+Y** とする。Three.js の Y-up 規約に従い、
  真上から見ると六角形が正対する
- 六角格子は軸座標（axial coordinates）で保持し、描画時に直交座標へ変換する

### 数値モデルの確定済み契約

次の事項は `TASKS.md` の T1-0 で確定した。詳細は `tasks/T1-0/DESIGN.md`、決定理由は
`tasks/T1-0/DECISIONS.md` を正とする。

- 過飽和度は遠方の氷に対する相対過飽和度 [%]、入力範囲は `[0,30]`、ダイヤグラム y 座標は `σ%/30`
- 基底面 CA は Reiter `α=1`、`dt` は物理秒でない CA step、許容範囲は `(0,1]`
- 各 CA step は、その条件サンプルから得た `β` を受け取る。step の開始時に外周 reservoir
  ring だけを新しい `β` で置換して拡散へ使い、終端でも同値へ固定する。内部の非受容水量場や
  既に凍結した部分は再スケールしない。開始時・終端の `β` 置換量と `γ` 面外入力は別々に
  収支台帳へ記録する
- 同一 seed・同一条件軌跡の再生キーには、各 step の条件、較正 ID、`β`、`γ`、ゆらぎ振幅、
  `dtCa` を順序付きで保存する。PRNG は作者参照実装 xoshiro128** version 1.1、モデル版は
  `reiter-alpha1-xoshiro128ss-1.1-v1` に固定する
- 形態指標は有限値または明示的な `null` だけを返し、厚み未指定または基底面直径 0 の
  `aspectRatio` は `null` とする
- 形態指標、性能測定条件、収支の決定的集計順、六腕 CV と許容範囲は T1-0 設計書の契約に従う

ただし、`(T,σ∞)` から `β`、`γ`、ゆらぎ、c 軸厚みへの数値写像と形態クラス閾値は
**第一原理ではなく経験的較正**である。`β`、`γ`、ゆらぎ候補の数値写像は T1-8、
c 軸厚みは T1-4、形態クラス閾値は T1-10 の承認前に仮値を実装してはならない。

### 適用範囲・近似

- 本モデルは**単一の結晶が一様な環境を経験する場合**を扱う。結晶まわりの水蒸気場の
  枯渇は CA が局所的に表現するが、雲スケールの輸送は扱わない
- 着氷・融解・昇華を扱わないため、実際の降雪で多数を占める不規則な結晶は再現できない。
  本アプリが再現するのは中谷ダイヤグラムに現れる整った形態である
- 板／柱の交替の機構は未解明であり、本アプリの再現は現象の**記述**であって説明ではない
- 外周 reservoir は、Reiter 原著の初期 seed から一定 Euclidean 距離にある境界を、計算領域と
  同じ axial 六角 ring で近似する。この近似は物理法則ではない。T1-9 の感度ゲートで、
  T1-0 設計書が定める比較専用共通場から各比較格子を初期化し、共有座標の `waterMass`・
  `ice`・`noise` の bit-for-bit 一致と各 checkpoint までの同一 control prefix を検査した上で、
  境界形状・境界距離の感度オラクルを production 半径で満たす場合にだけ採用する。満たさない
  場合は経験パラメータを調整せず原著相当の Euclidean 境界へ差し戻す

### 境界・不正入力時の挙動

- 有限な温度・過飽和度が定義域外のとき、最も近い境界値にクランプし、UI に範囲外である旨を示す。
  NaN / Infinity はクランプせず入力エラーとする
- 水蒸気量に負・非有限値が生じてはならない。生じた場合は実装のバグである
- 結晶が格子の外縁に到達したら成長を停止し、UI に通知する（格子を無音で拡張しない）
- **計算結果に NaN / Infinity を含めない**

## ユーザー体験

### 入口と導線

単一画面。3D ビューポート＋中谷ダイヤグラム操作盤＋タイムライン＋情報バー＋ヘルプ。

### 入力と操作

| 対象 | 操作 |
|---|---|
| 温度・過飽和度 | **中谷ダイヤグラム上のマーカーをドラッグ**（主操作）。ドラッグ中は成長が進む |
| 成長の開始・停止 | ボタン。停止中もダイヤグラム上でマーカーを移動できる |
| 成長速度 | スライダー（シミュレーションのステップ間隔） |
| 時間の巻き戻し・早送り | タイムラインのドラッグ |
| カメラ | 軌道回転・パン・ズーム |
| リセット / 新しい結晶 | ボタン。seed を変えるか同じ seed を使うか選べる |
| 結晶の保存・比較 | 現在の結晶を並べて表示する |

### 出力と可視化

- **3D の結晶**: 基底面の CA 結果に、温度から決まる c軸方向の厚みを与えた立体
- **中谷ダイヤグラム**: 形態領域をラベル付きで表示し、**マーカーが通った軌跡を線として
  重ね描く**。これが「この結晶がどんな条件を経てきたか」の記録になる
- **タイムライン**: 成長の各時点にスクラブできる
- **情報バー**: 現在の温度・過飽和度、経過ステップ数、結晶の最大半径

### 空・エラー・非対応状態

- 成長開始前は、ダイヤグラムをドラッグするよう促す案内を表示する
- WebGL2 非対応時は、その旨を明示するメッセージを表示する
- 結晶が格子外縁に達したら「これ以上成長できません」と表示する

### アクセシビリティ受入基準

- 中谷ダイヤグラムの操作を**キーボードでも行える**（矢印キーで温度・過飽和度を変更）
- 温度・過飽和度・形態領域名を、色や位置だけでなくテキストでも提示する
- 形態領域の区別を色のみに依存させない（ラベルと境界線を併用する）
- タイムラインをキーボードで操作できる
