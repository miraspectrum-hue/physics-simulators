# プリズム分光シミュレータ

正三角柱プリズムによる白色光の分散（七色への分離）を、ブラウザ上で 3D にリアルタイム可視化するインタラクティブ・シミュレータです。プリズムの回転・移動・入射角を操作すると、光路がその場で追従します。

> 参考イメージ（`prizm.png`、本プロジェクト直下）は本アプリが目指した見た目の**デザイン参照**であり、実際のアプリ画面のスクリーンショットではありません。実行画面の画像は現時点で用意できていないため、本 README への埋め込みは省略します。

## 起動手順

前提: Node.js 20.19 以上 または 22.12 以上、Chrome 最新版（WebGL2 必須）。

```bash
cd prism-sim
npm install

npm run dev       # 開発サーバを起動 → http://localhost:5173
npm run build     # 型チェック（tsc --noEmit）+ 本番ビルド → prism-sim/dist/
npm run preview   # ビルド成果物をローカルで確認
npm run test      # Vitest を実行
npm run typecheck # 型チェックのみ
```

## 操作方法（要約）

- **スライダー**: 入射角、ビーム幅、分散の誇張倍率（×1 が物理的に正しい値、上げるほど分離を強調表示）、スクリーンまでの距離、プリズムの姿勢（回転・位置）など
- **セレクト**: ガラスの材質（BK7 / SF10 / 水 / ダイヤモンド）
- **ラジオボタン**: スペクトル表示（連続 48 波長 / 7 色）
- **キーボード**: <kbd>R</kbd> 回転ギズモ、<kbd>G</kbd> 移動ギズモ、<kbd>Esc</kbd> カメラ操作へ戻る
- **マウス**: ドラッグでカメラを周回
- **表示トグル**: グロー（Bloom）、数値情報バー、断面 2D ビュー
- **保存・共有**: 現在の画面を PNG として書き出し／現在の状態を URL に反映して共有・復元

詳細な操作説明はアプリ内の「？ ヘルプ」ボタンから確認できます。

## 物理モデル（要約）

屈折率はガラスの分散を表す **Cauchy の分散式** `n(λ) = A + B / λ²`（λ は µm）で波長ごとに求め、スネル則で屈折・全反射を計算しています。頂角 60° の正三角柱プリズムに対し、最小偏角 δ_min（`δ_min = 2·asin(n_d · sin(A/2)) - A`）となる入射角へ自動で遷移させる機能もあります。「分散の誇張」スライダーは ×1 のとき常に物理的に正しい値になり、それより上げた分は見やすさのための誇張表示です。

材質定数の出典・臨界角・全反射条件など計算仕様の詳細は [SPEC.md](../../docs/simulators/prism-sim/SPEC.md) の「光学モデル」節を参照してください。
