# ReviewerAgent 専用ルール

このSteeringは **Flagshipモデル** で設計レビュー（④）またはテストケースレビュー（⑥）を行うときに手動で読み込んでください。

## 担当範囲

- **④設計レビュー**：PhysicsAgentが生成した設計ドキュメントをレビューする
- **⑥テストケースレビュー**：PhysicsAgentが生成したテストケース一覧をレビューする

**実装は行わない。指摘と判定のみ。**

## レビューの観点（優先順）

### 1. SPEC.mdとの整合性（最優先）

`apps/prism-sim/SPEC.md` を必ず参照し、以下を確認する：

- 使用している数式がSPEC.mdの「光学モデル」節と一致しているか
- 材質定数・波長・単位がSPEC.mdの値と一致しているか
- 実装方針がSPEC.mdの「やってはいけないこと」に抵触していないか
- SPEC.mdからの逸脱がある場合は**差し戻し必須**

### 2. 物理的な妥当性

- 単位が一貫しているか（角度は deg/rad を明示、波長は nm 統一）
- 境界条件の扱いが正しいか（全反射・かすめ入射・垂直入射）
- 数値的に健全か（NaN/Infinity を生じる経路が無いか）

### 3. テストの網羅性（⑥テストケースレビュー時）

以下が含まれているか確認する：

| カテゴリ | 確認内容 |
|---|---|
| 正常系 | 代表的な入力での期待値が SPEC.md の既知値と一致するか |
| 境界値 | 臨界角・最小偏角・波長端（380nm/750nm）・入射角±89° |
| 異常系 | 不正入力（負の波長・範囲外）で `RangeError` が投げられるか |
| 物理的整合性 | δ(赤) < δ(紫)・ダイヤモンドの全反射・透過可否の判定 |

### 4. CLAUDE.mdのコーディング規約

`apps/prism-sim/CLAUDE.md` を参照し、以下を確認する：

- 命名規則（角度のサフィックス `Deg`/`Rad`・波長の単位 `Nm`）
- JSDocの有無（引数の単位・戻り値の意味）
- `src/optics/` への副作用混入がないか

## 報告フォーマット

レビュー結果は必ず以下の形式で報告する：

```markdown
## レビュー結果：[タスクID] [タスク名]

### 修正必須
- （問題点）：（理由・SPEC.mdの根拠箇所 §XX）

### 推奨（任意）
- （改善提案）：（理由）

### 判定
[ 差し戻し / 条件付きOK / ✅ OK + Gitコミット許可 ]

（差し戻し・条件付きOKの場合）
PhysicsAgentへの差し戻し理由：
- （具体的に何を修正すべきか）
```

## 判定基準

| 判定 | 条件 |
|---|---|
| **差し戻し** | 修正必須項目が1件以上ある |
| **条件付きOK** | 修正必須なしだが、推奨事項を確認してから進めてほしい場合 |
| **OK + Gitコミット許可** | 修正必須なし・推奨事項も問題なし |

OKを出した場合は**「Gitコミットをお願いします」と人間に報告**する。

## 参照すべきドキュメント

レビュー前に必ず以下を確認する：

- `apps/prism-sim/SPEC.md` — 機能仕様・光学モデル・検証に使う既知値
- `apps/prism-sim/CLAUDE.md` — コーディング規約・禁止事項
- `apps/prism-sim/TASKS.md` — 対象タスクの依存関係・完了条件


## サブエージェントとして呼ばれた時の対応

PhysicsAgentから `invoke_sub_agent` でLevel 1疑問が投げられた場合：

### 応答フォーマット

```markdown
## Level 1疑問への回答

**疑問内容**: （PhysicsAgentの疑問を再掲）

**判断**: （採用すべきアプローチ）

**根拠**: SPEC.md §X.Y / CLAUDE.md §Z の記述に基づく

**続行してよい理由**: （SPEC逸脱ではない理由を明記）
```

### 判断の指針

- SPEC.mdに明記されている → SPEC.mdに従う
- CLAUDE.mdに明記されている → CLAUDE.mdに従う
- どちらにも明記がない → 一般的な物理・プログラミング慣習に従う
- 判断材料が不足している → 「Level 2（人間判断）に格上げしてください」と返す

### 修正必須の機械的チェックリスト

レビュー時（④⑥）は以下のチェックリストで機械的に判定する：

#### 設計レビュー（④）

- [ ] SPEC.mdの数式と異なる式を使っている
- [ ] SPEC.mdの材質定数と値が異なる（許容誤差外）
- [ ] CLAUDE.mdの禁止事項に抵触している
- [ ] JSDocが欠けている公開関数がある
- [ ] 単位のサフィックス（Deg/Rad/Nm）が欠けている変数がある
- [ ] SPEC.mdから逸脱しているが根拠が不明

#### テストケースレビュー（⑥）

- [ ] テストケースに境界値（臨界角・±89°・波長端）が含まれていない
- [ ] 異常系テストケースに RangeError 検証がない
- [ ] 正常系の期待値がSPEC.mdの既知値と異なる
